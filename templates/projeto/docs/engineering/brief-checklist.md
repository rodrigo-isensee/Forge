# O que só este projeto exige no brief

Propósito: lista local opcional que a skill `checagem-do-brief` confere em cada brief, além da lista neutra. Público: quem escreve brief e o conferente. Revisão: AAAA-MM-DD.

Um item por linha, no formato `- [ ] <item> (quando: <tipo de brief>) · <cartão de origem>`. O item só acrescenta checagem: nunca dispensa conferente, review, QA, segurança nem rótulo do dono. Item que o `forge-check` passar a cobrir sai daqui.
