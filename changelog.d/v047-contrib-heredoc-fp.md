### Corrigido
- Hook parecer (R-REVIEW e R-CONTRIB): o corpo de heredoc que só o Python lê da entrada (python3 -, também atrás de timeout) e que só cita comandos de PR em texto (string, comentário, docstring) deixa de contar como comando de PR; o corpo de sh que só lê ou espera (echo, cat, grep, sleep) não liga a gramática com heredoc. Seguem recusados o comando de PR lançado pelo Python (subprocess, os.system, asyncio, posix_spawnp, getattr com nome montado, lista em várias linhas ou concatenada), o executado pelo sh, o comando real fora do heredoc e os donos com caminho, atribuição, PATH, script ou pipe. Afrouxa a rede D da ADR 0011 para Python (emenda na ADR; HOOK-CONTRIB-HEREDOC-FP, HOOK-REVIEW-HEREDOC-TIMEOUT).
