### Corrigido
- hooks/conformidade.py: a troca de branch na linha (git switch, git checkout) só vale certa quando o operador garante que ela rodou; com ';', '||' ou '|' a branch de antes segue candidata e a de integração decide (S22: 'false && git switch -c x; git push' na main é recusado)
- hooks/conformidade.py: o resto com barra depois de $(…), crase ou variável ("$d/.", "$(echo .git)/.", "$@"/c) recusa como o literal quando o valor calculado cai no .git ou o texto que o produz o cita (A20)
- hooks/conformidade.py: o resto que sobe com '..' depois de $(…), crase ou variável vale resolvido ('TMPDIR=.git; cp x "$(mktemp -u)"/../config' e '"$X/a/../../config"' gravavam .git/config) (RESTO-SOBE)
- hooks/conformidade.py: com a troca de branch incerta, o merge confere cada candidata e o push usa a da regra mais dura, main antes de develop ('false && git switch develop; git merge develop' na main é recusado); a troca negada ('! git switch -c x && git push') não vale; o subshell segue a cadeia só se o começo dele garante a troca, e '(git switch -c x) && git push' deixa de ser recusado (S22)
- hooks/conformidade.py: o resto que se anula ou sobe depois de $(…), crase ou variável ('/.', '/..', '/a/..') vale como o destino sem resto ('TMPDIR=.git; cp ev/config "$(mktemp -d)"/..' gravava .git/config) (RESTO-ANULA)
- hooks/conformidade.py: a atribuição com '+=' junta os pedaços no texto que produz o valor ('d=.gi; d+=t; cp x "$d/c"' recusa) (A20)
- hooks/conformidade.py: na linha com lançador que o hook não lê ('builtin -iu', 'env -iu'), o resto com barra calcula o valor pelos corpos da palavra ('builtin -iu cp -rT ev ".g$(echo it)/c"' recusa) (A20)
- hooks/conformidade.py: a troca de branch só sai do subshell se é o primeiro comando dele; '(exit 0; git switch -c x) && git push origin' e a forma com 'exec' na main voltam a ser recusadas, e '(cd . ; git switch -c x) && git push' também (A3 da segurança E113.8)
- hooks/conformidade.py: o 'cd' dentro de '( … )' fica no subshell; '(cd /tmp); git push origin' na main é recusado (A4 da segurança E113.8)
- hooks/conformidade.py: a cópia recursiva ('cp -rT', 'cp -r ev/.', 'cp -a') para variável de fora da linha recusa como a cópia de arquivo; com o valor na linha ('d=docs') segue livre (A5 da segurança E113.8)
