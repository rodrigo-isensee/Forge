O `bin/forge-check` (modo `100755`, `#!/usr/bin/env python3`) roda pelo shebang quando os agentes o chamam pelo PATH (`forge-check pr`, `docs`, `delta`) e no `scripts/jarvis-forge:158-160` (`"$fc" fontes`).
