# R-DISCOVERY: Todo pedido começa com discovery

Propósito: texto único desta regra; os outros arquivos citam o ID. Público: todo o time. Revisão: 2026-10-12.

- **Todo pedido começa com discovery.** `ux-designer` (Design Thinking: empatizar, definir, idear, prototipar) e `software-architect` (viabilidade, dados, integrações, riscos, esboço de cada alternativa) trabalham em paralelo.
- Ponto de compromisso: o usuário valida o protótipo. Antes disso nenhuma demanda vai para "Pronto para fazer" nem entra em desenvolvimento; reprovado, o protótipo volta à etapa necessária.
- Só correção ou tarefa técnica sem impacto de interface pula o discovery (entra direto em "Pronto para fazer"), e o Jarvis avisa o usuário que pulou.
- Nenhum protótipo ou discovery novo sem pedido.
